# 📢 Sesecpro Security Advisories (SSA)

**Inteligencia de Amenazas Estratégica para la Alta Dirección y Equipos de IT.**

Este repositorio centraliza los análisis técnicos y alertas de seguridad emitidas por el equipo de inteligencia de **Sesecpro**. A diferencia de los boletines técnicos genéricos, nuestros **SSA** se centran en el impacto operativo y el riesgo de negocio, proporcionando guías de mitigación accionables para infraestructuras críticas.

---

## 🛡️ Taxonomía de Alertas

Clasificamos nuestras alertas según la naturaleza del riesgo y la audiencia objetivo:

* **🔴 SSA-CRITICAL:** Vulnerabilidades con impacto inmediato en el **P&L**, riesgo de exfiltración masiva de datos o parada de producción. Requiere acción en < 24h.
* **🟠 SSA-STRATEGIC:** Análisis de tendencias de cibercrimen, cambios regulatorios (NIS2/DORA) y riesgos geopolíticos. Dirigido al C-Level.
* **🔵 SSA-TECHNICAL:** Desgloses de exploits, firmas de detección (YARA/Sigma) y guías de *Hardening* avanzado. Dirigido a SOC/Blue Teams.
